# BambuFlow public roadmap

This roadmap reports intended work. It is not a promise of release dates or compatibility.

## R12 · Public technical preview

- [x] branded public URL;
- [x] local-first defensive 3MF preflight;
- [x] H2S/H2C guided configuration;
- [x] multiple optimization priorities;
- [x] nine preflight gates;
- [x] separate Bambu Studio Preview checklist;
- [x] reproducible JSON dossier;
- [ ] public issue templates.

## R12.4 · Machine-profile conversion

- [x] detect the machine identity embedded in the source 3MF;
- [x] show an explicit warning when source and selected target differ;
- [x] convert compatible Bambu-origin projects to resolved official H2S or H2C machine and process profiles;
- [x] reconcile supported Bambu filament identities while preserving project colours;
- [x] remove source G-code, checksums and slicing metadata before download;
- [x] preserve the model geometry byte-for-byte in the verified conversion case;
- [x] open the exact downloaded H2S and H2C candidates in Bambu Studio 02.08.04.61;
- [ ] re-slice and inspect each release candidate in Bambu Studio Preview before production use.

## R13 · Comparable optimization evidence

- [ ] controlled original/candidate slicing with the same supported slicer build;
- [ ] comparison of time, material, layers, supports, pauses, tool changes and Z height;
- [ ] automatic rejection and cleanup when a candidate has no measurable advantage;
- [ ] Mac Bambu Studio Preview validation after comparable re-slicing of the exact candidate;
- [ ] first documented physical qualification case.

## GitHub integration

- [ ] publish support and privacy information for the integration;
- [ ] implement the minimal Issues workflow against a selected test repository;
- [ ] verify installation, revocation and permission boundaries;
- [ ] register the GitHub App only after the real callback and webhook endpoints exist;
- [ ] open the first controlled public feedback cycle.

## Collaboration readiness

- [ ] present the four public surfaces as one connected Bambu-first environment;
- [ ] document representative anonymized cases;
- [ ] distinguish measured improvements from hypotheses;
- [ ] prepare an English technical dossier;
- [ ] verify trademark wording and project attribution;
- [ ] prepare a Bambu Lab collaboration proposal centred on reciprocal technical value;
- [ ] keep multi-manufacturer extensibility architectural, without diluting the current Bambu-first validation;
- [ ] request external collaboration only after the evidence package is complete.

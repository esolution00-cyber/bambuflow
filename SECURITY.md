# Security and privacy

## Public preview

The public BambuFlow preflight is designed to inspect the selected 3MF locally in the browser. Do not upload confidential customer models to third-party issue trackers.

## Reports

Please do not include any of the following in a public GitHub issue:

- customer or production 3MF/STL/OBJ files;
- printer access codes, account credentials or API tokens;
- private IP addresses, VPS configuration or server logs containing identifiers;
- personal data, order information or unpublished commercial material;
- proprietary presets or production dossiers.

Use a minimal, anonymized reproduction and describe the expected and observed behaviour. A private reporting channel will be published before the GitHub integration is made generally available.

## Printer safety

BambuFlow's public preview does not authorize or initiate printing, heating, motion, calibration or firmware changes. Treat every generated candidate as unverified until it has passed the declared digital and physical gates.
